# Raw data

Original files from the Utah FORGE extended circulation test, unmodified. Nothing in this folder is edited by the notebooks.

- Source: https://gdr.openei.org/submissions/1683 (DOI 10.15121/2475065)
- Licence: CC BY 4.0
- Authors: McLennan, J., England, K., & Swearingen, L. (2024)

Contents of `Extended Circulation Test/`:

| File | Content |
|---|---|
| `Extended Circulation Test Data 08082024 to 09052024 (30 sec increment).xlsx` | Raw, uncorrected time series, 30-second sampling |
| `Field Calibration of Flow Meters.xlsx` | Pump-truck rate against the three flow meters, 8 points |
| `Manual Temperature and Pressure Data.xlsx` | Manual temperature-gun and pressure-gauge readings next to the recorded values |
| `Extended Circulation Test Report-Final.docx` | Test report: schedule, correction methods, reference results |
| `Read Me.docx` | Column dictionary |
